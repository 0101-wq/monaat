# מונעת בביקור

אפליקציה לרופא המשפחה: רפואה מונעת ומעקב מחלות כרוניות לפי מטופל, לפי הנחיות רשמיות
(כוח המשימה הישראלי, משרד הבריאות, הר"י, ADA, ESC), כולל SCORE2, SCORE2-OP ו-SCORE2-Diabetes.

- כתובת: https://0101-wq.github.io/monaat/
- להתקנה בטלפון: לפתוח את הכתובת ולהוסיף למסך הבית.
- עובדת גם בלי אינטרנט. הנתונים לא נשמרים ולא נשלחים.
- כלי עזר להחלטה, לא תחליף לשיקול דעת קליני. המקורות המלאים בתחתית האפליקציה.
